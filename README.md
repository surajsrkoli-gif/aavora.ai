## About Aavora.ai

Aavora.ai is an independent project focused on making AI-powered creative tools more accessible to creators, developers, and digital artists.

The vision is to bring multiple AI creative workflows together in one platform with a simple and accessible user experience.

## Features

The platform is being developed with the following components:

- **Image Studio** – AI-powered image creation workflows.
- **Video Studio** – AI-assisted video creation workflows.
- **Script Studio** – Tools for creative script development.
- **Google Authentication** – User authentication powered by Firebase.
- **AI Integration** – Integration with generative AI services.
- **Creative Workspace** – A unified experience for AI-powered creative tasks.

*Features are under active development and availability may vary.*

## Technology

The project uses technologies and services including:

- HTML, CSS and JavaScript
- Firebase Authentication
- Cloudflare Workers
- Google AI / Gemini API
- GitHub Pages

## Project Status

Aavora.ai is currently under development.

Development has experienced some delays due to financial constraints and limited resources. However, the project remains active, and the goal is to complete the remaining development work and make the platform fully functional and publicly available as soon as possible.
